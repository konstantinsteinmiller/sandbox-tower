# Playtester 3 — desktop, persona: methodical reader

## Summary (5 lines max)
A merge-tower-defense game: place/merge blocks on a growing tower to fight off waves of monsters approaching from both sides of a river. Run 1 (guided by a good wordless tutorial) reached Wave 10/a boss fight before the base was destroyed, earning a solid meta-currency payout, a leaderboard rank, and unlocking a permanent tech tree. Run 2, started fresh with no tutorial, ended at Wave 1 because I placed only a defensive block with no weapon — enemies could not be killed and ground the undefended gate to zero in under a minute. The single biggest problem: the tower's own health bar looks identical to what I initially assumed was a "wave progress" meter, so I misread my most important stat for most of Run 1. A real placement bug (phantom buildable slots that silently fail) and two whole building types mentioned only in post-death tips (lumber huts/stone pits, multi-banner stacking) that I never found in two runs are the other standout gaps.

## Run 1 — what happened
- **~2s**: Game loads to Wave 0. A "MONSTERS INCOMING!" banner and a tutorial arrow point at a highlighted shop card; resource bar shows three unlabeled icons (120/40/0). No explicit written goal yet.
- **~4-11s**: Tutorial forces placing a Cannon block, then shows a wordless merge-chain diagram (white+white→green→blue→purple→orange…) — very clear, no text needed. A follow-up popup compares a basic cannon's damage (-10%) to my new merged tier-3 cannon's (-75%) against an enemy's HP bar.
- **~11s**: Tapping the placed block opens an info panel (HP/Damage/Cooldown/Range/Splash) with an UPGRADE button (paid in a 3rd, still-unnamed resource) and a dashed-circle range preview.
- **~15s**: Tutorial arrow points me to the CALL WAVE button (0:03 timer, +8% bonus for waiting) — I call it manually. Scene shifts to daytime; "WAVE 1 · ENEMIES 3" appears along with speed toggles (1x/1.5x/3x).
- **~23-30s**: Wave 1 resolves automatically (missed the actual fight during a wait); "WAVE 1 HELD" banner and floating resource rewards feel satisfying. I spend this lull hovering all 5 shop cards to learn Stone Block, Wood Crate, Archery, bulk Wood Crate, and Banner.
- **~31-63s**: Trial and error reveals two placement quirks: buying a card auto-arms a *new* random card immediately after placing (no need to reselect), and clicking certain "ghost" grid cells beyond the real buildable area shows a full placement preview that silently never completes (no resources spent, block vanishes later).
- **~58s**: A "SPEND!" nudge appears over an unlabeled green diamond icon — it opens a Tech Tree meta-progression screen. I buy Foundations rank 1 (+6% tower HP) with a new "star coin" currency.
- **~163-165s**: Discover the REPAIR button (unlabeled green "+", clears damage on blocks for a cost) and a Daily Missions panel (unlabeled clipboard icon) with 3 already-complete goals worth +180 star coins in one payout — a big, exciting windfall.
- **~168-255s**: Spend accumulated star coins across several Tech Tree nodes (Foundations, Sharpened Bolts, Long Sight), repair periodically, and keep building blocks through waves 5-9, each ending in a "WAVE X HELD" banner with resource rewards.
- **~332s**: CALL WAVE button turns into a red CALL BOSS button — an excellent wordless tension escalation.
- **~346-373s**: Wave 10 boss fight — a tree/troll monster with a distinctive orange health bar (vs. green for regular enemies) appears alongside reinforcements. Around 373s I finally notice the small bar under "WAVE 10" in the top-left, which I had assumed all game was a wave-progress meter, has turned red and is nearly empty — realizing only now that it is actually my base/tower HP.
- **~380s**: "DESTROYED!" — Run 1 ends. "YOU SURVIVED TO WAVE 10", "+186" star coins (new record), Best Score 138, global leaderboard Rank #293 of 361. A tip reads: "Lumber huts and stone pits pay you every wave" — buildings I never once saw or placed.
- **~381-389s**: The death-screen shop button reopens the Tech Tree with a 3-step tutorial (permanence, coin source, gold/blue/dim node coloring) I hadn't seen before — useful info that arrived only after I'd already inferred it myself by trial. Spend remaining 251 coins on more upgrades.

## Run 2 — what happened
- **~390s**: Fresh run starts via the death screen's "skip" button (not the paid "continue from Wave 9" option). Resources reset to 120/40/0, but all Tech Tree upgrades and star coins persisted (confirmed permanent). No tutorial banner/arrow this time.
- **~393s**: Deliberately let Wave 1 (4 enemies) auto-start with zero blocks built, to test what an undefended gate does (in character for a methodical/curious tester). Enemies reach the bare gate and attack it directly.
- **~407-414s**: The top-left HP bar visibly drains in real time as enemies hit the gate — confirms Run 1's discovery. I place one Stone Block (2x2, purely defensive/no weapon) on top of the gate.
- **~431-445s**: Because the Stone Block has no attack, the 4 enemies are never killed and keep hitting the gate; the HP bar goes from ~70% to a thin red sliver to empty.
- **~448s**: "DESTROYED!" at Wave 1 — only +5 star coins (vs. +186 in Run 1), a stark, well-communicated "this run was bad" signal. A new tip appears ("Banners boost every block they touch — and they multiply. Surround one gun instead of spreading them out") and a new purchase offer ("3x star coins for 30 [3rd resource]") that I could not afford (had 0 of that resource this run).

## Information gaps
1. **Base/tower HP bar looks identical to what I assumed was a wave-progress meter.** Seen from the very first screenshot (green, full-looking, under "WAVE 0/1/2…"), it never changed appearance in a way that corrected my assumption until it turned red near death in Run 1's boss fight (~373s). I misread my single most important stat for the entire first run. Evidence: `0002-wait.jpg` (assumed progress bar, green) vs. `0104-wait.jpg`/`0105-wait.jpg` (same UI element, red, critical) vs. `0128-wait.jpg` (Run 2 death, same bar emptied at Wave 1). Stayed unclear ~370 seconds. **Severity: High.**
2. **Resource icons are never named.** The wood-log, stone/brick, and third brown "gear-like" icon in the top resource bar are never labeled with text anywhere; I inferred "wood" and "stone" only from matching shop-card costs, and never learned the 3rd resource's actual name (used for Upgrade/Repair). Evidence: `0002-wait.jpg`, `0010-click.jpg`. Unclear for the whole session. **Severity: Medium.**
3. **Tutorial arrow overlay hides its own tooltip.** The very first tutorial-highlighted card's tooltip is partly covered by the down-arrow pointing at it, cutting off the item's name. Evidence: `0003-hover.jpg`. Momentary. **Severity: Low.**
4. **Silent-fail "phantom" placement slots.** Clicking certain grid cells that show the same light-blue "buildable" outline as real slots produces a full red placement preview that looks committed, but the resource cost is never deducted and the block silently disappears on the next action — no error sound, message, or shake. This happened to me twice and wasted real intent/time. Evidence: `0058-click.jpg`→`0059-wait.jpg` (block vanished), `0081-click.jpg`→`0082-shot.jpg` (same). **Severity: High.**
5. **Auto-rearmed placement after a purchase.** After placing a card, the same toolbar slot immediately refills with a new random item and stays "armed" for placement without another click on the toolbar — a further click anywhere (even on invalid terrain) can start placing something not consciously chosen. Evidence: `0025-click.jpg`→`0026-click.jpg`→`0027-shot.jpg`. **Severity: Medium.**
6. **Shop cards are randomized ("gacha") but this is never stated as a rule**, only implied by tooltips listing 2 possible outcomes for one price (e.g., "Wood Crate OR Archery" for the same card). No odds are shown. Evidence: `0017-hover.jpg`, `0057-click.jpg`. **Severity: Medium.**
7. **REPAIR button (green "+") is unlabeled.** I only understood its function (heal damaged blocks for a cost in the 3rd resource) by clicking it experimentally and comparing before/after screenshots. Evidence: `0062-wait.jpg` (badge appears, unexplained) → `0063-click.jpg` (effect). **Severity: Medium.**
8. **Daily Missions panel is an unlabeled clipboard icon.** I only opened it because a red notification badge appeared; nothing named it "missions" or "quests" beforehand. Evidence: `0064-click.jpg`. **Severity: Low-Medium.**
9. **Whole building types are teased but never discoverable in play.** Post-death tips reference "Lumber huts and stone pits" (passive per-wave resource income) and multi-Banner stacking, but across two full runs and constant hovering of every visible shop card, I never saw either of these things available to place. Evidence: `0106-click.jpg` (tip 1), `0128-wait.jpg` (tip 2). **Severity: High** — this is core content that appears completely gated behind something I never found (or is simply not reachable at my current progress).
10. **Tech Tree color-coding (gold=affordable, blue=needs coins, dim=locked) was explained only after my first death**, via a 3-step tutorial that popped up on my second Tech Tree visit post-run-1, despite the Tech Tree having been usable and used by me since ~58 seconds into Run 1. Evidence: `0038-click.jpg` (my first, unexplained visit) vs. `0110-click.jpg` (the tutorial, seen ~320s later). **Severity: Medium.**

## Incentive gaps
1. **No explicit written goal.** Nothing on screen ever states an objective like "Defend your tower — survive as many waves as possible." I inferred it from the "MONSTERS INCOMING" banner, the wave counter, and the CALL WAVE button by ~15 seconds, but a less attentive player might take longer. **Severity: Medium.**
2. **The two strongest motivators (Daily Missions payout, Tech Tree % upgrades) were both things I found essentially by accident**, triggered by small unlabeled badge icons rather than anything the game proactively introduced in the opening minute. A player who doesn't notice a tiny red "1" badge on an unlabeled clipboard could go an entire session without discovering either system. **Severity: Medium.**
3. **The death screen doesn't scale its tone to how badly the run went.** Run 2's 1-wave wipeout used the exact same layout as Run 1's Wave-10 finish, differing only in the reward number (+5 vs +186) and the italicized tip — there's no "that was a rough one, here's why" framing for a catastrophically short run, which is exactly the moment a new player most needs guidance. **Severity: Low-Medium.**
4. **Teased-but-unreachable content (lumber huts/stone pits, higher merge tiers shown with "…") creates curiosity without a visible path to it**, which is a double-edged sword: intriguing for a completionist, but potentially discouraging if a player can't find any way to progress toward it. **Severity: Medium.**
5. **No differentiated feedback for a "close call" wave clear.** Every "WAVE X HELD" banner in Run 1 looked and felt identical regardless of how much base HP I'd actually lost — because the HP bar itself was unclear (gap #1), I never got the "phew, that was close" adrenaline moment until the very end. **Severity: Medium.**

## What worked
- The wordless merge-chain tutorial diagram (white+white→green→blue→purple→orange) was immediately clear.
- Hovering any shop card or Tech Tree node reliably produces a clean, informative tooltip (stats, cost, effect).
- CALL WAVE turning into a red CALL BOSS button before Wave 10 was a great, wordless tension cue.
- Floating "+resource" numbers after each wave, and especially the Daily Missions coin shower (+180 in one go), felt genuinely rewarding.
- Permanent Tech Tree progression that visibly carries star coins and upgrade ranks across runs is a strong "why keep playing" hook, confirmed immediately at the start of Run 2.
- A global leaderboard rank (#293 of 361) on the death screen adds a light competitive incentive.

## Quit points
- **Run 1, ~124s**: Frustration at still not having found any base-HP indicator; persona (methodical reader) pushed through to keep investigating rather than quitting, but a less patient player might have bounced here.
- **Run 2, ~448s (right after the Wave-1 wipeout)**: Having just seen a strong Wave-10 run, a real player watching their base die at Wave 1 to enemies that were mechanically unkillable (no weapon placed, no warning that a purely defensive block does nothing offensively) could plausibly close the tab here — the loss feels arbitrary rather than instructive, since the root cause (base HP bar ambiguity, tooltip not warning "this block cannot attack") was never made clear.
- No true "I'd close the tab right now" moment during Run 1 itself — the steady drip of new discoveries (repair, missions, tech tree, boss) kept curiosity high throughout.

## Would you play a 3rd run? (1–5, why, and the single change that would raise it)
**3/5.** The permanent Tech Tree, the leaderboard rank, and curiosity about the still-unseen lumber huts/stone pits and higher merge tiers genuinely pull me back in. But the accumulated friction — phantom placement failures, and especially not being able to reliably read my own base health — undercuts confidence that I'm playing "correctly." **The single change that would raise this most: make the base/tower HP an unmistakable, clearly-labeled bar (with a heart/shield icon and a number, not a slim bar shaped identically to what looks like a progress meter).** That one fix would have let me manage risk properly in Run 1 and would have made Run 2's loss feel like a clear, fair lesson instead of a confusing surprise.
