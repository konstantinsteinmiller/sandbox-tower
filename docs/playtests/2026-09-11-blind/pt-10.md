# Playtester 10 — mobile, persona: curious explorer

## Summary (5 lines max)
Tower Siege dropped me straight into Wave 1 with zero explanation of goal, controls, or currencies. I spent the first ~4 minutes only using the VOLLEY button and drag-to-build, never realizing enemies can be tapped directly - a discovery I only made by accident after a reload made the game look "frozen." Both runs died at the exact same wave (8) to the same tree/ent boss, and the post-death screen showed the identical "Rank #322 of 361" both times, which reads as fake once you notice it twice. The permanent BLUEPRINTS upgrade shop (revealed only after a death) is the single clearest, most motivating piece of the whole experience. A drag-to-build mechanic that worked fine in run 1 stopped working entirely after a reload in run 2, which I never got working again.

## Run 1 — what happened
- **~0s:** Loading screen (100%), then straight into "Wave 1.1" with a "MONSTERS INCOMING!" banner and a glowing lane with a downward arrow. No goal statement, no control hints. Top bar shows three unlabeled numbers (wood-plank icon, puzzle-piece icon, gold-coin icon) and a bottom bar with a VOLLEY button and 3 unlabeled resource cards.
- **~3-14s:** Tried tapping VOLLEY repeatedly on a falling enemy; enemies died but I couldn't tell if VOLLEY, an auto-turret, or something else caused it.
- **~30-65s:** By trial and error, discovered dragging the bottom resource cards onto dashed grid outlines on the tower places building pieces (walls, an archer crate, etc.) and grows the tower. Nothing in the UI suggested this was possible.
- **~150s:** After Wave 7, a red "CALL BOSS" button appeared with a countdown - first signal a boss fight is coming.
- **~168-177s:** A tree/ent monster with a health bar (a clear step up from regular fodder) appeared at Wave 8 and destroyed the tower. Result screen: "Destroyed! You survived to wave 8. Rank #322 of 361. New Record! +59 gold."
- **~178-204s:** Tapped a green "WAVE 7 +240 🧩 30 🪙" button on the death screen expecting a menu - it instead resumed live gameplay at Wave 7 with a huge resource boost (wood 90→435, puzzle 8→55, gold 6→130), re-arming CALL BOSS. Not explained as a continue/revive at all.
- **~185-203s:** Played the replay; died again at Wave 8 to the same ent, identical death screen and identical rank (#322 of 361), but this time NO continue button - only a cart icon and a skip-forward icon.
- **RUN 1 END:** True end at ~203s (game time), Wave 8, twice, via a one-time free continue.

## Run 2 — what happened
- Explored the post-death cart icon: opened a "BLUEPRINTS" permanent-upgrade shop (gold-star currency, 188 available) with guided tooltips explaining costs are permanent, that coins come from every siege win-or-lose, and how the locked/unlocked node coloring works. Bought "Sharpened Bolts" rank 1 (+8% tower damage) for 20 gold - clear, satisfying, and unlocked the next node.
- Tapped skip-forward to start Run 2: fresh Wave 1, wood/puzzle reset to 90/0, but the 168 gold-star currency correctly persisted from Run 1 - good permanent-progression signal.
- **~210-238s:** Game appeared to freeze at "Wave 1.2" - one lone enemy sat still for 20+ seconds, VOLLEY, drag-building, and the menu button all did nothing. I would have assumed the game crashed. Reloaded to recover.
- **~238s:** After reload, tapped directly on the stuck enemy out of frustration - it died instantly. This revealed the actual core interaction (tap-to-attack enemies) that nothing in four minutes of prior play had shown me.
- **~251-260s:** Attempted drag-to-build several times (same coordinates/technique that worked in Run 1) - it never worked again for the rest of the run. Confirmed via unchanged currency after each attempt.
- **~260-378s:** Played waves 2-7 using only direct enemy-tapping plus the auto-firing cannon; steady progress, no near-losses, resources climbing higher than Run 1 at the same wave (gold 294 vs 101).
- **~378-406s:** Wave 8 boss (same ent) again. Discovered that tapping directly on the tower's own build slots (not enemies) can trigger a "CRUSHED!" combo effect with a large flashy number (140, then 80) - but this actually drained my wood currency to near-zero and locked out VOLLEY and all 3 build cards, the opposite of what the celebratory presentation implied.
- **~406s:** Died again at Wave 8 to the same ent. Identical result screen, identical "Rank #322 of 361" (third time seeing this exact number). New this time: an orange "3x ⭐ 30" button that showered coin icons on tap but never visibly changed the displayed "+54" total.
- **RUN 2 END:** ~406s (game time), Wave 8, same boss as Run 1.

## Information gaps
1. **Core goal never stated.** Saw "MONSTERS INCOMING!" and a tower at 0s, but never any text like "defend the tower" or "survive waves." I inferred the goal from context, not from the game. Severity: med.
2. **Direct tap-to-attack on enemies was never taught.** I played ~4 minutes purely with VOLLEY and building before discovering (by accident, after a "frozen" scare) that tapping an enemy sprite kills/damages it. Screenshot evidence: `0068-tap.jpg` (stuck state) vs `0072-tap.jpg` (enemy died after direct tap). Severity: high.
3. **Drag-to-build mechanic has zero onboarding and is undiscoverable without trial and error.** Nothing indicates the bottom cards are draggable, or that dashed squares on the tower are drop targets. Screenshot: `0016-drag.jpg` (first accidental success). Severity: high.
4. **Drag-to-build silently stopped working after a reload in Run 2** and never recovered for the rest of the run (`0062`–`0082-drag.jpg`, currency unchanged across 5+ attempts). A real player would think building is broken, not know it's a session bug. Severity: high.
5. **VOLLEY button's function/cooldown was unclear for the first ~50 seconds.** First use at ~3s showed no cooldown badge; only later did a red countdown appear. Screenshot: `0023-tap.jpg`. Severity: low-med.
6. **No tower/gate health bar anywhere.** Enemies visibly hit the door (`0042-wait.jpg`, a "4" damage number on the gate) but I had no persistent HP readout to gauge danger, so death at Wave 8 both times felt sudden rather than telegraphed. Severity: high.
7. **Three top-bar currencies (wood-plank, puzzle-piece, gold-star) are never labeled or explained** on first sight - I had to infer "wood = build currency, puzzle = repair currency, gold = permanent meta-currency" purely from later context (repair costs puzzle pieces, blueprints cost gold). Severity: med.
8. **REINFORCED HAND button's effect was unexplained** - discovered by comparing before/after prices that it resets escalated build costs, but no tooltip or label said so. Severity: med.
9. **CRUSHED! tower-slot-tap mechanic is actively misleading.** Big celebratory text and numbers (140, 80) accompany what is actually a resource drain that locks out your build options. Screenshots: `0113-tap.jpg`, `0118-tap.jpg`. Severity: high.
10. **The 3x reward button's effect was invisible** - coins animated flying but the earned total displayed (+54) never changed to reflect a tripling. Severity: low.
11. **Icons for buildable pieces don't match what gets built** (e.g., a paper-airplane icon produced a crossbow/archer crate). Screenshot: `0019-wait.jpg`. Severity: med.
12. **Rank "#322 of 361" was identical across all three death screens** in two different runs with different scores/resources - this reads as a static/fake number once repeated, undermining trust in the whole results screen. Severity: med-high (trust issue, not a mechanical blocker).

## Incentive gaps
1. **The one clear, motivating incentive (the BLUEPRINTS permanent-upgrade tree) is hidden behind a death and an unlabeled shopping-cart icon.** A player who quits before losing once - a very plausible outcome given the information gaps above - never sees it. Severity: high.
2. **No goal or reward preview before playing** - the game never told me "beat wave X to unlock Y" or showed a roadmap, so early motivation was purely curiosity, not a stated incentive. Severity: med.
3. **The free "continue" after Run 1's first death was unexplained and felt arbitrary** - I didn't know if it was a one-time gift, an ad reward I skipped, or a bug, so I can't tell a real player what to expect or plan around. Severity: med.
4. **Both runs hit the exact same wall (Wave 8, same boss) despite Run 2 having far more accumulated resources and a bought upgrade** - the difficulty spike felt like a hard gate rather than a skill/build check, which is discouraging for a "try again" loop. Severity: high.
5. **No visible session goal/streak/daily-return hook** was ever shown (no "come back tomorrow for X", no login streak, no next-milestone teaser) in either run or on any death screen. Severity: med.

## What worked
- The auto-firing cannon and archer crates gave a satisfying "my tower is fighting back" feeling once built, and Wave-Held banners with gold rewards ("+15", "+21", "+32") gave clear per-wave positive feedback.
- The BLUEPRINTS shop's guided tooltip sequence (three short tooltips: what it is, where coins come from, how node coloring works) was the best-explained system in the whole game - concise and immediately actionable.
- Meta-currency (gold-star) correctly and visibly persisting between runs (168 → carried forward) delivered a real "my run wasn't wasted" feeling.
- Direct enemy-tapping, once discovered, was immediately satisfying and responsive.

## Quit points
- **~230s (Run 2, mid-Wave 1):** The apparent freeze - no enemy movement, no button response for 20+ seconds - is exactly the moment a real player closes the tab, assuming a crash. I only continued because I'm instructed to keep trying; a genuine first-time player has no such obligation.
- **~204s (end of Run 1) and ~406s (end of Run 2):** Dying at the identical wave to the identical boss with an identical (and suspicious) rank number both times would make a real player feel the run outcome is scripted/static rather than earned, reducing the incentive to try a third time.

## Would you play a 3rd run? (1–5, why, and the single change that would raise it)
**2/5.** The core loop (build tower, watch it fight, occasionally tap things) is mildly satisfying, and the permanent upgrade shop is a genuine hook - but I hit the same boss wall twice with no sense of what to change, the drag-build mechanic broke on me and never recovered, and the "frozen" scare in Run 2 nearly made me quit outright. The single change that would raise this most: **teach tap-to-attack and drag-to-build explicitly in a first-run tutorial**, and **show the BLUEPRINTS shop (or at least tease it) before the first death**, not only after.
