# Playtester 1 — desktop, persona: casual portal browser

## Summary (5 lines max)
A tower-defense/merge-building hybrid: build a wall+tower structure from wood/stone, call waves of monsters, survive as long as possible, spend earned "coins" on a permanent tech tree between runs. The opening tutorial is genuinely well-guided, but the block-placement puzzle silently fails on cells that look identical to valid ones, costing real time and, in Run 2, directly caused an early death. Both runs ended being "DESTROYED" at a boss gate (wave 10, then wave 5). The strongest hook is the permanent tech tree (visibly paid off on Run 2's fresh start); the biggest missed opportunity is a Daily Missions system that sat completed-but-unclaimed the entire session because its icon gives no hint it holds rewards.

## Run 1 — what happened
- **~0s:** Game opens mid-tutorial: "MONSTERS INCOMING!" banner, Wave 0, resources shown (wood/stone/gold), a "Call Wave" button counting down, and a yellow arrow pointing at a highlighted tray item labeled "REINFORCED HAND 30." No explicit goal text anywhere yet — goal is inferred from context, not told.
- **~1–10s:** Followed the arrow: placed the item on the wall → a merge-chain popup appeared explaining tier1+tier1=tier2 up to tier5 → a damage-comparison popup (-10% vs -75%) → clicked the placed cannon to open its detail panel (HP/DMG/COOLDOWN/RANGE/SPLASH, an UPGRADE button) → bought the upgrade → followed the arrow to the "Call Wave" button → Wave 1 (3 enemies) began, speed controls (1x/1.5x/3x) appeared.
- **~10–90s:** Wave 1 auto-resolved off screen with no visible danger. Build phase: placed several tray pieces (wood crates, a stone block, a second cannon, an archery tower), but repeatedly hit cells that looked exactly like working ones yet did nothing when clicked — no error, no shake, no sound. Spent real time (multiple failed clicks) on a 3-wide "Roofed" wood crate that needed a wider base than I had.
- **~90s–6 min:** Waves 3–9 mostly auto-resolved (towers auto-fire; I only acted between waves). Opened the "Tech Tree" (via a diamond icon that gave a red "spend" badge once I had coins) and bought Foundations (+HP), Sharpened Bolts (+damage), Long Sight (+range), Lumber Stockpile (+starting wood).
- **~6.8 min (408s):** Wave 9 introduced a "CALL BOSS" button (first hint of a boss) and I noticed, for the first time, small HP bars under individual placed blocks. Wave 10 boss (a dead-tree monster + goblins/wolves) broke through — **DESTROYED**. Result screen: "YOU SURVIVED TO WAVE 10," "NEW RECORD! +223" coins, Best Score 134 (a number that didn't obviously match the record just earned), Rank #295 of 361 (a global leaderboard exists), and a tip about lumber huts/stone pits.
- Post-death, opened the Tech Tree again and it now showed a 3-step tutorial explaining the coin economy and node color-coding — useful information that arrived only after my first death, not before I'd already used the tree blind for six minutes. Used a free, instant "continue" button (Wave 9, structure fully intact, +100 wood/+100 stone, no ad) → played to a second DESTROYED at wave 10 again (score 133, one short of the record). This continue was one-time only — a later death showed no such button.

## Run 2 — what happened
Started a genuine fresh restart via the death screen's "skip forward" button. Confirmed permanent progression carried over: starting wood was 140 instead of the original 120 (matches the Lumber Stockpile purchase), and coins persisted.
- **0–2s:** Placed the starting combo piece (crate+cannon) successfully on the first try.
- **~2–15s:** Tried repeatedly to place the second tray item; every click on the highlighted cells failed silently again. Gave up and let waves proceed with only the single starting tower defending.
- **Waves 1–4:** Held fine despite the thin defense (enemy counts were still low).
- **Wave 5 (~157s into this run):** **DESTROYED** — score only 43 (versus Run 1's 133+), directly because the single tower couldn't handle the wave-5 enemy count. This is a clean demonstration that the placement-UX confusion isn't just annoying, it materially hurts performance exactly like it would for a real confused player.
- Post-death screen showed the same green continue + shop cart + skip options, plus a coin-count animation that briefly reads like a purchasable "3x" button but is just a tally effect, not a real option.
- Briefly started a third attempt purely to check a persistent, unexplained clipboard icon (bottom-left, permanent red "1" badge) — it opened "Daily Missions": three missions (Earn 1 coin, Defeat 60 enemies, Place 1 block) were **already completed and unclaimed**, worth 180 coins total, sitting there the entire two-run session because I never had a reason to click that icon.

## Information gaps
1. **No explicit stated goal.** Saw: Wave 0 screen, "MONSTERS INCOMING," a wave counter. Never understood: an actual sentence telling me the objective (survive waves / defend the castle) — I inferred it entirely from context clues (banner text, "You survived to wave X" on death). Unclear from 0s to end of session. Screenshot: `0001-shot.jpg`. Severity: medium.
2. **Unlabeled third HUD resource.** Saw: three resource counters at top (wood, stone, and a third icon that looked like gears/components) plus a separate purple in-run currency spent on upgrades, plus star-coins for the tech tree — four currencies total. Wood and stone got tooltip names; the third HUD icon never did. Unclear the whole session. Screenshot: `0019-click.jpg`. Severity: medium.
3. **Silent placement failures.** Saw: red-outlined "valid" looking grid cells. Didn't understand: why clicking them sometimes did nothing (no cost deducted, no piece placed, no error/shake/sound) versus working elsewhere — turned out pieces must connect directly to already-built structure, but nothing on screen said so. First hit ~30s into Run 1, recurred through both runs, and directly caused Run 2's early death at wave 5. Screenshots: `0027-click.jpg`, `0028-click.jpg`, `0063-click.jpg`. Severity: **high**.
4. **Tray items require a click to learn anything.** Saw: generic icons in the build tray with no persistent name/cost label. Didn't understand: what any item did until clicking it to open its tooltip, every single time the tray cycled. Whole session. Screenshot: `0015-click.jpg`. Severity: medium.
5. **Unexplained mystery button.** Saw: a green button with a "+3" cost badge that appeared bottom-left mid-run (~wave 5, Run 1). Didn't understand: what it did — clicking it spent 3 of the purple resource and left an oddly-placed piece floating over the water with no visible effect or explanation. Never resolved. Screenshot: `0068-click.jpg`. Severity: medium.
6. **Tech Tree color legend arrived too late.** Saw: gold/blue/dim colored nodes in the Tech Tree from the very first time I opened it (~85s). Didn't understand: what the colors meant (gold=affordable, blue=needs more coins, dim=locked behind a prerequisite) until a 3-step tutorial appeared — but only after my *first death*, roughly 6 minutes after I'd started using the tree blind. Screenshots: `0054-click.jpg` (blind use) vs `0106-click.jpg`/`0107-click.jpg` (the tutorial, post-death). Severity: medium.
7. **Individual block HP bars easy to miss.** Saw: small green/yellow slivers under placed blocks starting around wave 6–9 of Run 1. Didn't understand until wave 9 (~400s in) that parts of my structure could take and show localized damage — nothing called this out when it first happened. Screenshot: `0102-wait.jpg`. Severity: low-medium.
8. **"Best Score" number didn't match the record I'd just set.** Saw: "NEW RECORD! +223" directly above "Best Score: 134" on the same screen. Didn't understand whether these were different units (coins vs. some other score metric) or if the display was simply stale. Persisted across both death screens. Screenshot: `0104-shot.jpg`. Severity: low.
9. **Daily Missions completely invisible.** Saw: a clipboard icon with a permanent red "1" badge, visible in literally every screenshot from the start. Didn't understand it held anything — never clicked it during either full run. Turned out to contain 3 already-completed, unclaimed missions worth 180 coins. Unresolved for the entire two-run session (~620 seconds) until I deliberately went looking afterward. Screenshot: `0141-click.jpg`. Severity: **high**.

## Incentive gaps
1. **Free instant continue undercuts stakes.** After the first death, a green button revived me at the same wave with my structure fully intact plus bonus resources, no ad, no cost. It's generous, but it also means the first defeat didn't feel like a real setback — and when a *second* death offered no such button, that inconsistency felt arbitrary rather than earned. Screenshots: `0114-click.jpg` / `0115-click.jpg` (offered) vs `0119-wait.jpg` (not offered next time).
2. **Combat is almost entirely hands-off.** Towers auto-fire; after the initial 20-second build phase, most waves were pure spectation for 10–20 seconds at a stretch with nothing to click. This is fine as a novelty but risks boredom for a low-patience player once the initial "wow" of the tutorial fades (roughly the wave 4–9 stretch of Run 1).
3. **Daily Missions — a whole reward layer with zero pull.** Since I never noticed the clipboard icon meant anything, an entire "come back and complete goals for coins" loop had zero effect on my motivation to continue, even though it's exactly the kind of feature meant to bring players back. See Information Gap #9.
4. **Useful tips arrive only after they're too late to use.** Tips like "Two identical weapons side by side fuse into one" or "Banners boost every block they touch" appeared only on death screens, after the run that needed them had already ended, and nowhere else (no in-game help/info button). Screenshots: `0104-shot.jpg`, `0138-wait.jpg`.
5. **No preview of wave difficulty scaling.** Enemy counts jumped unpredictably between waves (7 → 16 → 23 in Run 1) with no forewarning, so there was no way to judge "should I build more before calling this wave" — progress felt more like luck than a legible risk/reward decision.

## What worked
- The very first 10–20 seconds are a clean, well-guided tutorial: arrow → place item → merge-chain popup → stat comparison → upgrade prompt → call wave. Every highlighted target did something when clicked.
- Combat has satisfying juice — damage numbers, explosions, particle bursts — that made even passive waves fun to watch.
- The Tech Tree is a strong "just one more run" hook: permanent stat boosts, a clearly-stated currency source ("Coins come from every siege, win or lose"), and — critically — I *saw* the payoff on Run 2's fresh start (140 starting wood instead of 120), which is exactly the kind of visible progress that keeps a player coming back.
- Unlocking a brand-new placeable item (Spiked Wall) via the tech tree felt like a genuine, tangible reward for spending currency.
- The day/night cycle and a dedicated "CALL BOSS" button (versus the normal "Call Wave") built real tension heading into wave 10.
- An unexpected global leaderboard rank (#295 of 361) is a nice light competitive hook I wasn't expecting.

## Quit points
- **~30–55s into Run 1:** Several consecutive silent placement failures on a 3-wide crate piece, with zero feedback on why. A real low-patience portal player would very plausibly have closed the tab here, inside the first minute, before ever seeing a wave resolve.
- **Waves 5–9 lulls (Run 1, roughly 2–6 minutes in):** Extended stretches of pure spectation with nothing to interact with. If this happened before the tech tree hook had registered, it's a real bail-out risk.
- **Two deaths in a row at the identical wave 10 boss (Run 1):** hitting the same wall twice with no new information about how to get past it could easily read as "I've seen everything this game has" rather than "I should try again differently."

## Would you play a 3rd run? (1–5, why, and the single change that would raise it)
**3/5.** I did, in fact, start a third attempt (to go check that clipboard icon), and the tech-tree payoff genuinely makes me curious to see the new Spiked Wall in action. But the repeated placement-puzzle friction and the passive middle-game stretches cool my enthusiasm each time they happen. **Single highest-impact change:** fix the block-placement feedback — only highlight cells that are actually placeable right now, or give an immediate visual/audio "no" (shake + reason) when a click fails. That one fix would have both prevented Run 2's early death and made the core building loop feel good instead of frustrating.
