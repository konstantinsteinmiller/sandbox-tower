# Playtester 4 — desktop, persona: progression chaser

## Summary (5 lines max)
A merge-tower-defense game (place/merge blocks on a castle wall, survive waves, big boss every 10 waves). The core loop is genuinely satisfying for a progression chaser: a permanent gold-funded Tech Tree that survives death, Daily Missions with a coin-shower payout, and a global leaderboard rank on every death screen gave me real reasons to keep going. But the game is stingy with explanations at exactly the wrong moments — key mechanics (tech tree color coding, the "coins persist between runs" rule, the Banners mechanic, the reroll button) were only explained by trial-and-error or, worse, buried in a tutorial hidden behind an icon on the SECOND death screen. Run 1 reached wave 10 (killed by a big boss); Run 2 reached only wave 5 because I spread defenses thin without knowing better. I would play a third run, but the frustration of learning-by-dying rather than being told upfront cost real enjoyment.

## Run 1 — what happened
- **~0 s**: Game opens mid-tutorial. Wave 0, resources (wood/stone) visible, a highlighted item with an arrow pointing at it. No goal text at all yet — I inferred "place this on the wall" purely from the highlight.
- **~5 s**: After placing the first block, a wordless animated diagram showed tiles merging 1→2→3→4→(5?). This taught the merge mechanic without a single word of text — worked, but only because I was already looking for it.
- **~10 s**: First enemy (a boar) appeared and died to my single cannon before I'd upgraded anything. No enemy info card, no health/damage numbers shown up front.
- **~12 s**: An "UPGRADE" button appeared with an arrow pointing at it (24 gold) — this is when I first understood gold exists as separate from wood/stone.
- **~30–60 s**: Learned by trial and error that placement requires being adjacent/connected to existing structure (red border = just-placed/selected, not necessarily invalid; actual invalid spots simply don't deduct resources and don't move).
- **~150 s**: First real Tech Tree purchase (Foundations, +6% tower HP, 20 gold). Discovered the Daily Missions panel (3/3 already complete) by noticing a tiny red badge — big coin-shower payout, very satisfying.
- **~260–330 s**: Built up 3 towers total (1 cannon, 1 archer pair, 1 more cannon) plus some stone/wood filler blocks. Spent gold on 4 tech tree nodes (Foundations x3, Sharpened Bolts x2, Long Sight, Lumber Stockpile).
- **~300 s**: Wave 9 held triggered a red "CALL BOSS" button replacing "Call Wave" — a great escalation cue.
- **~310–337 s**: Boss wave 10: a large tree/root monster appeared, dealt 50+ damage per hit, and tore through the right side of my wall in about 15 seconds, destroying two blocks and the corner cannon before reaching the door.
- **RUN 1 END (~337 s)**: Tower DESTROYED at wave 10. Result screen: "NEW RECORD +267" (score), Best Score 160, Rank #274 of 361 (global leaderboard). A tip appeared: "Lumber huts and stone pits pay you every wave. Two or three change what you can afford" — first mention of these buildings, never seen in-game.

## Run 2 — what happened
- Clicked the blue "skip forward" button on the result screen, which immediately started a fresh siege at Wave 0. Wood/stone/blocks reset to defaults, but gold (310, carried over) and all Tech Tree ranks persisted. This was the first clear proof that gold/tech is a permanent meta-currency — I had only inferred it before.
- **~340–345 s**: Spent gold in the tech tree, discovering two new locked root branches: "Harbour" (710 gold, unlocks ships that hit submerged foes) and "Logistics" (110 gold, unlocked the Stone Pit, a passive producer). Bought Logistics and one Yields node.
- **~349–410 s**: Built a much thinner defense than run 1 this time (rushed to spend on tech tree instead of towers) — one wood-crate cluster, one cannon, one archer.
- **~420–490 s**: Waves 1–4 held without much trouble, but I noticed enemies swarming both sides of the wall with my minimal defense.
- **~510–522 s**: Wave 5, 17 enemies, wave health bar in the top-left went red/critical.
- **RUN 2 END (~522 s)**: Tower DESTROYED at wave 5, worse than run 1. Score this run: 44 (vs. best 160). Rank unchanged (#274/361, meaning run 1 stayed my best). A NEW tip appeared: "Banners boost every block they touch — and they multiply. Surround one gun instead of spreading them out" — a mechanic (Banners) I had never seen or heard of, explaining exactly why spreading my defenses thin this run was the wrong call.
- Clicked the shop-cart icon expecting an IAP store; instead it opened the Tech Tree with a 3-step tutorial I'd never seen: (1) "Coins come from every siege, win or lose. This is where you spend them," (2) "Gold nodes you can afford now. Blue need more coins. Dim need the node before them." This finally explained the tech tree's color coding — after two full runs of guessing.

## Information gaps
1. **No stated goal at game start.** What I saw: Wave 0 screen with a highlighted item and no text. What I didn't understand: what the objective is (survive waves? reach a wave count? get a high score?) beyond what I could infer from context. When: 0 s. How long unclear: never explicitly stated in either run; I inferred "survive as long as possible" only from the death screen's "YOU SURVIVED TO WAVE X" framing. Screenshot: 0001-shot.jpg. Severity: medium.
2. **Block placement rules undocumented.** What I saw: clicking an empty cell sometimes placed the item (green highlight, resource deducted) and sometimes silently did nothing (red preview, no deduction, no message). What I didn't understand: that new blocks must be adjacent/connected to the existing structure. When: ~50–55 s in run 1. How long unclear: about 10–15 s of confused trial and error each time I tried a "floating" cell. Screenshot: 0035-click.jpg / 0036-click.jpg. Severity: medium.
3. **Placed blocks can be visually indistinguishable from the background.** What I saw: a Stone Block I paid 16 stone for produced no visible new sprite — it blended perfectly into the existing stone tower art. What I didn't understand: whether the purchase succeeded at all; only clicking to inspect it (and seeing its HP/Armour stats) confirmed it existed. When: ~29 s in run 1. How long unclear: until I specifically re-inspected the block, about 15–20 s later. Screenshot: 0022-click.jpg. Severity: medium.
4. **The reroll button's function was unlabeled.** What I saw: a green button (bottom-left) showing a small cost (e.g. "+3") next to the item tray. What I didn't understand: that clicking it rerolls/replaces the currently offered tray item; found out only by clicking it blind. When: ~193 s. How long unclear: until that one click. Screenshot: none saved from that exact click, but noted in-session. Severity: low.
5. **Tech Tree color coding (gold/blue/dim) was never explained until after two deaths.** What I saw: nodes in three visual states throughout both runs, with no legend. What I didn't understand: which color meant "affordable," "needs more gold," or "needs a prerequisite." When: first tech tree open at ~45 s in run 1; the explanation only appeared at ~526 s (after both deaths) via a tutorial hidden behind a shop-cart icon on the death screen. How long unclear: the entire ~480 s of active play across both runs. Screenshot: 0028-shot.jpg (unexplained state) vs. 0152-click.jpg (the tutorial, finally). Severity: high.
6. **"Lumber huts and stone pits" and "Banners" mechanics were only ever introduced via post-death tooltips, never in-game.** What I saw: two separate death-screen tips referencing buildings/mechanics (economy producers, banner buffs) I had never encountered, been shown, or been able to build knowingly. What I didn't understand: how to get these buildings, when they unlock, or how banners work mechanically. When: end of run 1 (~337 s) and end of run 2 (~522 s). How long unclear: still unclear at end of session — I never saw these systems in actual gameplay, only referenced in tips. Screenshots: 0112-click.jpg, 0149-wait.jpg. Severity: high (directly caused my run 2 loss — I "spread out" my guns not knowing Banners rewarded clustering).
7. **The third resource (called "planks"/supplies in the top bar) had unclear purpose beyond paying for some blocks and the reroll.** What I saw: it climbed into the hundreds (up to 308) with no visible sink besides occasional 20-48 cost items and the 3-cost reroll. What I didn't understand: whether I was hoarding it uselessly or missing a bigger use for it. When: throughout both runs. Severity: low.
8. **The two locked Tech Tree root branches (Harbour, Logistics) were unlabeled/unexplained until directly clicked.** What I saw: two grayed-out tree roots on the right side of the tech tree UI. What I didn't understand: what they unlocked until I spent time clicking into each one. When: ~342 s. Severity: low.

## Incentive gaps
1. **Gold (meta-currency) persisting through death was never stated up front — it was a huge motivator once I understood it, but I only found out by accident.** What would have helped: a one-line confirmation the very first time gold appears ("Gold is kept forever, even if you lose"). Severity: high — this is the single most important progression-chaser hook in the game and it's under-communicated.
2. **Daily Missions existed and were already 3/3 complete the first time I opened them, with a satisfying coin-shower claim animation — but the panel's notification badge was tiny and easy to miss.** A first-time player who doesn't notice a small red "1" on a clipboard icon could go an entire session without claiming free rewards. Severity: medium.
3. **The escalating "CALL WAVE → CALL BOSS" button color change (blue to red) was a great tension-building signal** that made we want to prepare before wave 10 — this was one of the best-executed incentive moments in the whole session.
4. **Losing run 2 felt worse than losing run 1** because the death-screen tip revealed I'd made an avoidable mistake (spreading guns instead of clustering with Banners) that the game never warned me about beforehand — this created frustration rather than a "next time I'll do better" feeling, since I still don't know how to access/build Banners.
5. **The leaderboard rank (#274 of 361) on both death screens was a nice touch for a progression chaser** — it gave me a concrete competitive number to chase — but it didn't move between runs even though my second run scored much lower, so it wasn't clear if the leaderboard rank was live or a static "best run" placeholder.
6. **No visible indicator of what unlocks at future waves/tiers** (aside from discovering the boss at wave 10 by surprise). A prior hint like "Boss incoming in 3 waves" would have let me prepare and increased anticipation rather than surprise-then-frustration.

## What worked
- The permanent Tech Tree with visible % bonuses (HP, damage, range, wood/stone income) is an excellent progression-chaser hook once understood — watching numbers like "+24% total HP" accumulate felt great.
- Daily Missions with an obvious, satisfying coin-shower claim animation.
- The escalating CALL WAVE → CALL BOSS button (color/label change) built real tension.
- The wordless merge-tutorial (tile 1→2→3→4→5 animation) taught the core merge mechanic clearly without any reading required.
- Gold/rank/score summary on every death screen gave me something to compare across runs.
- Enemy variety (goblins, boars, skeletons, flying enemies, a giant boss) kept visual interest high even in a short session.

## Quit points
- **~50–55 s into run 1**: When block placement silently failed with no resource deduction and no on-screen explanation, I nearly assumed the game was broken. A first-time player less patient than a progression chaser might have closed the tab here thinking the controls didn't work.
- **~522 s (end of run 2)**: Losing worse than run 1, then discovering via a hidden tutorial that I'd been missing a core mechanic (Banners) the entire time, was the low point of the session. A player without a reason to keep chasing gold/tech-tree progress (i.e., not this persona) would likely quit here rather than start a third run "blind" again.

## Would you play a 3rd run? (1–5, why, and the single change that would raise it)
**3/5.** The permanent gold economy and tech tree are genuinely compelling — I want to see the Harbour and Logistics branches fully unlocked, and I want to know what a leaderboard climb from #274 looks like. But two runs of learning core mechanics (placement rules, tech tree colors, Banners) entirely through trial-and-error and after-the-fact tooltips left me frustrated rather than excited. The single change that would raise this to a 4 or 5: **surface the Tech Tree's color-coding tutorial and the "Banners" mechanic explanation the first time each system is relevant in-game (not buried in a death-screen shop icon)** — that alone would have made both runs feel like informed strategy instead of guesswork.
